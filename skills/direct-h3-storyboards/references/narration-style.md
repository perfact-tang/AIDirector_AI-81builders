# 配音叙述风格与无生图文字转场规范

## 一、配音叙述风格（audio_plan.audio_text）

配音词必须听起来像**懂行、真诚、逻辑清晰的真人主播在面对面聊天讲解**，绝不能像念论文、念 PPT、念说明书或写散文诗。

### 核心气质与写法

1. **说人话，短中句交替，有口语呼吸感**
   - 优先使用自然口语连接词，如：「简单来说，就是……」「先从……说起」「接下来切换到……」「举个例子……」「但它也有一个局限……」「这时候就可以考虑……」「最后，我们把……放在一起看」。
   - 少用生硬书面语（如「综上所述」「鉴于上述因素」「旨在实现」「赋能」），多用直白动词和生活化表达。
   - 严禁出现画面元描述（绝不能写「画面中我们看到……」「镜头缓缓推近……」）、严禁出现 `(S1)`、`[旁白]`、`(No dialogue)`、舞台指示或 Markdown 符号。

2. **开场直击痛点与连续设问（Hook）**
   - 知识讲解、技术对比、产品/概念解读类源文，前 1–3 个镜头先用真实场景中的困惑开场：点出大家常碰到的名词或难题 → 连续抛出 1–2 个具体选择问题 → 一句话给出本片承诺（「这个视频我们就把……从原理到应用场景一次讲清楚。」）。

3. **讲解结构：痛点场景 → 一句话定义 → 工作方式/关键组成 → 接地气的例子 → 优缺点与边界**
   - 每引入一个概念，先给一个具体场景（如「平时收藏的文章、写的笔记散落在各处」「公司有几千份文档，员工想查一条报销规定」），再用「简单来说，就是……」一句话讲透本质。
   - 拆解机制时按「第一步……第二步……」或「主要有三个部分……」清晰分步，不堆砌术语。
   - 尽量配一个具体可感的例子（「举个例子，员工问公司的差旅报销标准是多少……」）。
   - 客观给出局限与取舍（「它的优势是……但它也有一个局限……」「所以如果只是普通的……没必要一上来就用……」）。
   - 结尾做横向对比与选型收束（「如果你要……可以考虑……」「最重要的不是……而是先搞清楚自己的……再决定……」）。

4. **叙事/故事类源文的口语化原则**
   - 故事类保留源文人物对白与关键事件，旁白同样采用自然讲述口吻，节奏利落、有情绪停顿，避免冗长定语和拗口长句。

5. **严格匹配镜头时长的字数控制**
   - **5 秒镜头**：建议 **16–24 个汉字**（或等时长英文约 10–15 词），保证单句或两短句完整说完，不超速、不生硬截断。
   - **10 秒镜头**：建议 **34–48 个汉字**（或等时长英文约 22–30 词），可容纳「引入 + 解释」或「举例子 + 结论」两到三句自然衔接。
   - 一段话说不完时，按自然意群和停顿拆到下一镜，不要硬塞进单个镜头。

### 正反示例对比

- **反面（生硬书面/空洞）**：「RAG 是一种检索增强生成技术，它能够有效提升大语言模型在企业知识库场景中的信息检索准确率与回答可靠性。」
- **正面（自然口语解说）**：「RAG 全称叫检索增强生成，你可以简单理解为：先让 AI 找资料，再让大模型根据找到的资料回答问题。」

## 二、无生图模式下的场景差异化与文字转场规范

本应用不内置逐镜生图，**每个镜头的画面变化与转场完全依赖 `image_prompt` 与 `video_prompt` 的精确文字导演描述**。如果相邻镜头描述雷同，或错误滥用 `use_previous_frame: true`，H3 会反复生成几乎一模一样的静止画面。

### 强制防重复与视觉演进规则

1. **相邻镜头禁止重复构图与场景复读**
   - 相邻两镜（例如 SHOT-003 与 SHOT-004）的 `image_prompt` 和 `video_prompt` 不得雷同或只改几个字。
   - 每切换一个镜头，必须在以下 4 个维度中**至少改变 2 项**：
     - **景别变化**：大远景 / 全景 / 中景 / 近景 / 局部特写 / 俯视微缩视角；
     - **机位与角度**：平拍 / 高角度俯拍 / 低角度仰拍 / 侧面跟拍 / 过肩视角 / 主观视角；
     - **空间与视觉意象**：切换真实环境区域，或用具体可视化隐喻场景（如发光文件夹迷宫、实体关系连线图、企业档案大厅、分层业务沙盘）呈现不同知识点，而不是一直让角色站在同一个背景前说话；
     - **主体动作与道具交互**：每镜必须有明确的物理动作（转身、伸手点亮节点、翻开文档、推开光门、走入新空间）和动态运镜（推进、拉远、横移、环绕、俯冲）。

2. **明确区分「切新场景」与「尾帧续接」**
   - **`SHOT-001` 永远设 `use_previous_frame: false`**。
   - **切换话题、切换地点、切换景别/机位或引入新概念时**：`use_previous_frame` **必须设为 `false`**。并在 `video_prompt` 开头明确写清切换方式与全新空间（如：「【硬切新场景】俯拍视角切入宽敞的企业档案大厅……」），确保与上一镜形成鲜明视觉对比。
   - **仅在同一空间内、动作紧接上一镜结尾的连续镜头**才设 `use_previous_frame: true`；连续启用 `use_previous_frame: true` 原则上**不超过 2 个镜头**，避免画面僵化。
   - 启用 `use_previous_frame: true` 时，`video_prompt` 必须明确写出「**从上一镜尾帧状态立即推进**：镜头迅速变化机位/推进，主体完成全新动作并抵达新的结束画面」，绝不能停留在原姿态重复上一镜的画面！

3. **`image_prompt` 与 `video_prompt` 清晰分工**
   - `image_prompt`（首帧/核心构图提示词）：精准写出本镜头**独有的空间环境、景别、机位角度、光线色温、前景/背景道具和主体站位**，体现与上一镜的明显差异。
   - `video_prompt`（动态分镜提示词）：写出**起势 → 中段核心动作与运镜变化 → 结束定格状态**的完整 5 秒或 10 秒动态过程，让画面从第 1 秒到最后 1 秒持续发生变化。
